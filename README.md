# Classio

Classio is an e-learning platform where teachers can teach and students can learn online.  
Teachers can create subjects and classes, upload course materials, and manage students.  
Students can browse subjects, enroll in classes, and access learning materials after payment.

---

## 🚀 Features

### Teacher
- Create subjects and classes  
- Upload course materials (notes, videos, assignments)  
- Manage student join requests (accept/reject)  
- Track enrolled students and their progress  

### Student
- Browse available subjects  
- Enroll in classes  
- Access course materials after payment  
- View class schedule and join online classes
